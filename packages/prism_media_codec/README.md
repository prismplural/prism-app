# Prism Media Codec

App-owned native static-image normalization for Prism.

This package is a Flutter native-assets package backed by Rust and
`flutter_rust_bridge`. It lives in `prism-app` so media encoding dependencies do
not become part of `prism-sync`, whose ownership boundary is sync, relay, and
sync-owned FFI.

## Behavior

`encodeImage` resizes a single static image within the supplied bounds and
chooses a storage format based on real alpha use:

- Images with transparent pixels become lossless WebP.
- Opaque images become JPEG at the requested quality.
- Animated formats should be detected before calling this package so animation
  is not flattened to one frame.

The Rust `image` dependency is intentionally built with only `gif`, `jpeg`,
`png`, and `webp` enabled. Do not add codecs that require platform C libraries
or extra toolchains without checking Android, iOS, macOS, Linux, and Windows
native-assets builds.

## Generated Code

Bindings are generated by `flutter_rust_bridge`. If the Rust FFI surface
changes, regenerate from the package directory and commit the generated Dart and
Rust files:

```bash
flutter_rust_bridge_codegen generate
```

## Tests

Run the package Rust tests first:

```bash
cd packages/prism_media_codec/rust
cargo test
```

Then run the app tests that exercise the package through native assets and real
media call sites:

```bash
flutter test test/core/services/media/image_compression_service_test.dart test/shared/utils/profile_header_image_normalizer_test.dart test/e2e/media_codec_native_assets_smoke_test.dart
```
